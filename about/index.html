This Website

This site is not representative of any employers or organizations that I may be affiliated with. Its purpose is solely for me to have a centralized place where I can write about things related to my career or personal interests and contribute to the larger infosec community.

It’s likely that many pages will be modified continually. Webpages with recently-changed content will log when the update occurred, but no other details are currently exposed on the site. Public version history can be viewed on GitHub.

Most pages are generated with Hugo using modified versions of Tinyblog and Tinyimages by Marcus Butler. I plan to write and release a custom theme in the future when the site is more developed.

Keyboard Shortcuts

The following keybinds can be used to interact with the site:

  • Esc - toggle menu
  • / - search
  • T - toggle theme
  • C - toggle contents (on applicable pages)
